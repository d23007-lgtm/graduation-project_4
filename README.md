# こだわりをたどる｜Craft Discovery

工芸以外を専門とするデザイン学生・クリエイターが、自分の興味を手がかりに「こだわり」を通して工芸の人物・作品・考え方を探索し、制作の発想のきっかけを得るための卒業研究プロトタイプです。

## ファイル
- `index.html`：画面構造
- `style.css`：デザインとスマートフォン対応
- `script.js`：探索、検索、絞り込み、詳細、関連リンク、保存・メモ

## GitHub Pagesで公開する
1. GitHubでリポジトリを作成します。
2. このフォルダ内の4ファイルをリポジトリの最上位へアップロードします。
3. `Settings → Pages` を開きます。
4. Source を `Deploy from a branch`、Branch を `main`、フォルダを `/(root)` にして保存します。
5. 公開処理後、Pages設定に表示されるURLを開きます。

## 内容を編集する
`script.js` 内の `interests` と `items` を編集します。各アイテムの `links` は `[対象id, 関係を説明する文章]` の配列です。リンク先のidが実在する対象のidと一致していることを確認してください。

## 研究内容の注意
初期データは画面と操作を検証するためのサンプルです。人物・作品の情報、こだわりの解釈、歴史的な関係は、公開前に文献・展覧会図録・所蔵館情報などで確認してください。本人が明言した考え方と、作品・活動から読み取った解釈は区別してください。出典欄の「未入力」を調査後に具体的な資料名・URL・ページ番号へ置き換えてください。

## 画像について
カード画像は外部画像に依存しないCSSグラフィックです。実際の作品画像へ置き換える場合は、著作権・利用条件・クレジット表記を確認してください。

## 保存機能
保存した対象とメモはブラウザの `localStorage` に保存されます。端末間では同期されず、ブラウザデータ削除時に失われる可能性があります。
